# HTTCmd

**フォルダーをドラッグ＆ドロップするだけで、HTTP サーバーが起動。**

HTTCmd は、作成中の静的サイトをブラウザーで確認したり、フォルダー内のファイルを配信したりできる Windows 向けの軽量 HTTP サーバーです。

- **約 156 KiB の EXE ひとつ。** 配布アーカイブを展開すれば、インストーラー不要で起動できます。
- **公開したいフォルダーをドロップするだけ。** エクスプローラーからフォルダーを `HTTCmd.exe` にドラッグ＆ドロップすると、そのフォルダーがドキュメントルート（DocRoot）になり、ポート `80` で起動します。同じ PC のブラウザーで `http://localhost/` を開くと確認できます。
- **ドメイン名ごとに公開先を切り替え。** `/H` を使えば、同じサーバー・同じポートで、アクセス先のホスト名に応じて別々のフォルダーを配信できます。複数の静的サイトを並行して確認するときに使えます。

## 自宅の PC 1台で、ドメインごとにサイトを配信

ブログと写真ギャラリーなど、複数のドメインで静的サイトを運用する自宅サーバーにも使えます。たとえば `blog.example.com` と `gallery.example.net` を同じ自宅サーバーに向けておけば、HTTCmd を1つ起動するだけで、ドメインごとに別々のフォルダーを配信できます。

`/H` に渡す `C:\www\DocRoots.tsv` に、ホスト名と公開フォルダーをタブで区切って記述します。

```text
blog.example.com	C:\www\Blog
gallery.example.net	C:\www\Gallery
```

```bat
HTTCmd.exe "C:\www\Default" 8080 /H "C:\www\DocRoots.tsv"
```

未登録のホスト名には `C:\www\Default` が使われます。インターネットに HTTPS で公開する場合は、手前のリバースプロキシで HTTPS を受け、元の `Host` ヘッダーを保ったまま HTTCmd に転送します。

## コマンドで起動する

1. Windows 11 で配布アーカイブ `HTTCmd.zip` を展開します。HTTCmd は `HTTCmd.exe` 単体で起動できます。
2. 公開用フォルダーを用意し、トップページとして表示するファイルを `index.html` という名前で配置します。
3. コマンドプロンプトで `HTTCmd.exe` のあるフォルダーに移動し、次のコマンドを実行します。例では `C:\www\DocRoot` を公開します。

   ```bat
   HTTCmd.exe "C:\www\DocRoot" 8080
   ```

4. ブラウザーで `http://localhost:8080/` を開きます。例えば、公開用フォルダーの `files\guide.pdf` には `http://localhost:8080/files/guide.pdf` でアクセスできます。

停止するには、別のコマンドプロンプトから次を実行します。複数の HTTCmd サーバーを起動している場合は、まとめて停止します。

```bat
HTTCmd.exe /S
```

アンインストールするには、サーバーを停止して展開したファイルを削除します。

## 起動コマンド

```text
HTTCmd.exe [DOC-ROOT [PORT-NO [OPTIONS...]]]
```

- `DOC-ROOT` は公開するフォルダーです。省略すると、コマンドを実行した時点のカレントディレクトリを公開します。`.` でも指定できます。
- `PORT-NO` は待ち受けポートです。省略時は `80` です。使用中のポートを避けるには、空いているポートを指定します。
- オプションを使うときは、公開フォルダーとポート番号の両方を指定します。

```bat
HTTCmd.exe . 8080 /K
```

| オプション | 動作 |
| --- | --- |
| `/K` | 起動したコンソールでキーを押すと停止します。 |
| `/T TSV-FILE` | 拡張子と `Content-Type` の対応を追加・上書きします。 |
| `/H TSV-FILE` | リクエストの `Host` ヘッダーに応じて公開フォルダーを切り替えます。未登録のホストには起動時に指定した公開フォルダーを使います。 |
| `/N HTML-FILE` | ファイルが見つからない場合に、指定した HTML を HTTP 404 のページとして返します。 |
| `/C` | ファイルのレスポンス本文をチャンク形式で転送します。 |

`/T` と `/H` の設定ファイルは UTF-8 のタブ区切りテキストです。見出し行を付けず、各行に2列を記述します。

- `/T` はドット付きの拡張子、`Content-Type` の順です。例は `.svg` と `image/svg+xml` です。
- `/H` はポート番号を除いたホスト名、公開フォルダーの順です。例は `localhost` と `C:\www\LocalSite` です。

## 配信の仕様

- ディレクトリの URL では `index.htm`、次に `index.html` を探します。どちらもなければ HTTP 404 を返します。
- 対応するメソッドは `GET` と `HEAD` です。配信対象は静的ファイルです。
- サーバーはすべての IPv4 インターフェースで HTTP 接続を待ち受けます。ネットワークやファイアウォールの設定によっては別の端末からもアクセスできるため、公開してよいファイルだけを配置してください。
